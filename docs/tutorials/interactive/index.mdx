These pages run Nucleide right here — no Python or Rust installation is
required; every example is live.

<Callout type="info" title="How it works">
  Each demo runs the same Rust code that powers the Python package, compiled
  to run on this page through a small JavaScript API.
</Callout>

## Available interactive tutorials

- [Nuclides & nuclear data](nuclides.mdx) — name conversions, masses, abundances, half-lives.
- [Materials](materials.mdx) — formula expansion, atom/weight fractions, mixing, XML export.
- [Enrichment cascades](enrichment.mdx) — solve matched-abundance-ratio cascades.
- [Depletion](depletion.mdx) — load a chain and run one CRAM step.
- [MCNP I/O](mcnp-io.mdx) — parse material cards, xsdir, meshtal, and WWINP files.
- [Serpent output](serpent-io.mdx) — parse `_res.m`, `_dep.m`, and `_det.m` MATLAB-style files.
- [FLUKA USRBIN](fluka-io.mdx) — read USRBIN mesh tallies from `.lis` output.
- [Variance reduction](variance-reduction.mdx) — MAGIC bounds and alias-table source sampling.
- [Activation](activation.mdx) — ALARA decks and output, FISPACT-II inventories, ORIGEN tapes, R2S workflows.
- [Deterministic transport](deterministic.mdx) — ISOTXS libraries, RTFLUX fluxes, PARTISN decks.
- [Deck editor](deck-editor.mdx) — parse, validate, and edit full MCNP decks.
- [Code-card emission](emitter.mdx) — five-dialect cards, ARMI keys, and mass drift.
- [Point kinetics](kinetics.mdx) — step-reactivity transients and the prompt jump.
- [Tritium permeation](tritium.mdx) — 1D breakthrough curve and time lag.
- [Gamma-ray spectroscopy](spectroscopy.mdx) — smoothing and peak counting.
- [UQ sampling](uq.mdx) — seeded MVN sampling over caller-supplied covariance blocks.
- [MCPL particle lists](mcpl-io.mdx) — read/write MCPL bytes and SSW conversion.
- [Damage metrics](damage.mdx) — fold a multigroup flux into dpa and gas production.
- [Fusion sources](fusion-sources.mdx) — sample D-D/D-T ring, point, and
  parametric sources (including fuel mixtures) and emit SDEF cards.
- [Spectrum unfolding](unfold.mdx) — SAND-II, least-squares, and GRAVEL adjustment over detector measurements.
- [Clearance screening](clearance.mdx) — sum-of-fractions classification against EU or Spanish limits.
- [TBR bookkeeping](blanket.mdx) — raw and effective TBR, breeding margin, and daily burn and surplus.
- [Equilibrium data](equilibrium.mdx) — INDATA parsing and wall-load mapping in flux coordinates.

## When the live demos are not enough

The live demos are a teaching and exploration tool. For production work—large
chain files, full transport decks, batch processing — use the Rust crate API or
the Python package.
