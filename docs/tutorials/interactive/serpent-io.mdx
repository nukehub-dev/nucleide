The `serpent-io` crate reads Serpent's MATLAB-style output files, where every
quantity is a `NAME = [...];` assignment. The browser binding parses the text
and returns a JSON summary of every variable with its kind and shape, plus a
few headline values for results files.

## Supported formats

- **`_res.m` results** — run metadata, k-eigenvalues, and cycle statistics,
  accumulated across burnup blocks.
- **`_dep.m` depletion** — `ZAI`/`NAMES` inventories and per-material
  density, burnup, and source matrices.
- **`_det.m` detectors** — bin counts and per-detector tally tables with
  values and relative errors.
