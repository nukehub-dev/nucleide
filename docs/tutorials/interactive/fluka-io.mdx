The `fluka-io` crate reads USRBIN tallies from FLUKA `.lis` output files.
Each tally carries its Cartesian mesh bounds plus the paired track-length and
percentage-error data blocks.

## Try it

Paste a `.lis` snippet or load the sample tally, then inspect the tally
headers and view a z-slice of the mesh as a heatmap.
