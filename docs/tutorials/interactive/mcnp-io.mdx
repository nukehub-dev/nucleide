The `mcnp-io` crate reads and writes several MCNP-family file formats. In the
browser we can only work from text strings, which is still enough to inspect
decks and convert small files.

## Supported formats

- **Material cards** — `m1 92235 -0.04 92238 -0.96` style definitions, including
  comment metadata.
- **xsdir** — cross-section directory with AWR table and continuous-energy
  entries.
- **meshtal** — `fmesh` tally output with structured mesh results and relative
  errors.
- **WWINP** — Cartesian weight-window lower bounds.
