The `emit` crate renders one material through five code dialects — MCNP `m`
cards, Serpent `mat` cards, FLUKA `COMPOUND` cards, ALARA `mixture` blocks,
and single-zone PARTISN decks — and reports a per-dialect mass-drift table
with drop reasons plus re-parse verification where readers exist (MCNP,
ALARA). The ARMI blueprint bridge accepts post-expansion ARMI mass-fraction
keys (`nU235`, …) instead of GNDS names.

## Try it

Pick a key dialect, edit the composition JSON, set the material name,
density, and per-dialect options, then press **Emit**. Elemental keys, bare
`AM242`, and unknown names fail with an inline error instead of crashing.
