Nucleide exposes a typed pure-Python package at `python/nucleide/` that re-exports
a compiled PyO3 extension built from `bindings/python/`. The extension module is
named `nucleide._internal`; users import from the `nucleide` domain submodules,
which mirror the Rust workspace crates.

## Module layout

```python
import nucleide as nuc
```

The top level carries `version()`, `nucleide.__version__`, and the domain
submodules below (so `nuc.nuclei.Nuclide(...)` works directly). Each submodule
re-exports its symbols from `nucleide._internal`. If you are looking for a
task-oriented entry point rather than the full module map, jump to
[Common workflows](#common-workflows) below:

## Common workflows

The module sections below list every symbol; these are the shortest paths into
the most common tasks. Snippets use the same `from nucleide.<domain> import
...` idiom as the tutorials, which cover each workflow in depth.

### Parse a legacy output file

```python
from nucleide.mcnp import read_meshtal
from nucleide.serpent import read_serpent

tallies = read_meshtal("path/to/meshtal").tallies
res = read_serpent("path/to/filename_res.m", "res")
```

Tutorials: [Parse MCNP output](../tutorials/python/parse-mcnp-output.md),
[Parse Serpent output](../tutorials/python/parse-serpent-output.md),
[Parse FLUKA output](../tutorials/python/parse-fluka-output.md).

### Build a material

```python
from nucleide.data import fetch_compendium
from nucleide.material import MaterialsCompendium, from_formula

comp = from_formula("UO2")
lib = MaterialsCompendium.load(fetch_compendium())
```

Tutorial: [Build materials](../tutorials/python/build-materials.md).

### Run depletion

```python
from nucleide.depletion import deplete, read_chain

chain = read_chain("path/to/chain.xml")
out = deplete(chain, {"U235": 1.0, "U238": 20.0}, dt=1e6)
```

Tutorial: [Run depletion](../tutorials/python/run-depletion.md).

### Solve an enrichment cascade

```python
from nucleide.enrichment import Cascade

cascade = Cascade.default_uranium()
cascade.solve()
```

Tutorial: [Enrichment cascade](../tutorials/python/enrichment-cascade.md).

### Run a kinetics transient

```python
from nucleide.kinetics import solve

betas = [0.00021, 0.00141, 0.00127, 0.00255, 0.00074, 0.00032]
lambdas = [0.01, 0.03, 0.1, 0.3, 1.0, 3.0]
out = solve(betas, lambdas, Lambda=1e-5,
            rho={"kind": "step", "t_step": 1.0, "rho_init": 0.0, "rho_final": 0.002},
            t=[0.5, 1.0, 2.0], n0=1.0)
```

Tutorial: [Run kinetics](../tutorials/python/run-kinetics.md).
