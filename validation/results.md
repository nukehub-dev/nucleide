**2026-09-16**, inside the container built from `Containerfile`
(`./validation/run_container.sh`, podman). The environment versions were:

| Code     | Version | Source                                        |
|----------|---------|-----------------------------------------------|
| Nucleide | 0.12.0  | abi3 release wheel (maturin container)        |

schema default), and infinite half-spaces are bounded by the per-deck
cutoff recorded in the drift report. The structural probe verifies that
every reference (`solidref`, boolean `first`/`second`, `volumeref`,
`materialref`, `world`) resolves and that the document carries the pinned
schema version. Wherever `lxml` is importable (validation container), every
translated document is additionally validated against the runtime-fetched,
SHA-256-pinned XSD; a Geant4 load gate stays OUT (disproportionate
dependency for an emitter), and a missing validator degrades to a loud SKIP.
